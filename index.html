How to print from Electron

win.webContents.print({
  silent: false,
  pageSize: 'A4',            // or 'Letter' / 'Legal'
  margins: { marginType: 'none' },
  scaleFactor: 100,
  printBackground: true,
});

The pages have no print stylesheet; the sheet starts at the top-left corner, so the page size and zero margins must come from the print options above.

How to print from a browser

  1. Open a test page and press Ctrl+P (⌘+P on macOS).
  2. Choose the matching paper size.
  3. Set Scale to 100% / Actual size, not “Fit to page”.
  4. Set Margins to None and turn off Headers and footers (the pages have no print stylesheet, so these settings matter).
  5. Measure the printout: the outer border should be 0.25 in and the inner border 0.50 in from every edge.
